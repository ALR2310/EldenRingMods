# Menu texts in several languages

Status: **Confirmed** in released mods of the old repository (not yet re-tested in game from this one). Conventions:
[research notes](../../docs/research/README.md). Code: `shared/src/i18n.rs`.

## Mechanism

A mod keeps one JSON file per language in `locales/` with the same nested keys and embeds them in a
`Catalog`:

```rust
static TEXT: Catalog = Catalog::new(&[
    ("english", include_str!("../locales/en.json")),
    ("vietnamese", include_str!("../locales/vi.json")),
]);
```

The menu code names a key (`t("walk.label")`). The language is the host's identifier, set when the host
reports it (`i18n::set_language`). A missing key falls back to English, then to the key itself, so a
forgotten translation shows readable text instead of nothing. English is required.

## Test

`TEXT.assert_matches_source(include_str!("menu.rs"), n)` checks that every `t("key")` in the menu source is
in every language file and that the files hold nothing else; `n` guards against the scan finding nothing.
Write each key as a literal `t("...")` call so the scan sees it.
