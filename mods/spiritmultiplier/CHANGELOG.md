# SpiritMultiplier - Changelog

## [Unreleased]

- Fixed enemies being changed by the spirit AI options when another mod shares their AI with spirits.

## [1.5.0] - 2026-10-23

- Added option for more spirit HP bars.

## [1.4.0] - 2026-10-23

- Added summon instant Mimic Tear option.
- Fixed spirit warping errors on 1.17.2.
- Fixed the reload key working outside the game window.

## [1.3.1] - 2026-10-18

- Fixed Seamless Co-op failing to start when MaxSpirits is above 60.

## [1.3.0] - 2026-10-17

- Fixed Mimic Tear summoning fewer spirits than set.
- Fixed teleport options in the config file being ignored.
- Added in-game settings menu support (requires the ERNativeUI mod).

## [1.2.2] - 2026-10-10

- Fixed a crash when summoning the Mimic Tear in Seamless Co-op.

## [1.2.1] - 2026-10-09

- Fixed spirits not teleporting to you in Seamless Co-op.

## [1.2.0] - 2026-10-09

- Added options to improve spirit awareness and combat AI.
- Added options to teleport spirits to you more often.
- Added an option to summon extra copies of a spirit instead of sending it back.
- Added spirit HP regeneration options by flat HP and percent of missing HP.
- Fixed extra spirit summons not costing FP or HP.
- Fixed turning off no-rest summoning not working.
- Fixed re-summoning a dead spirit needing two presses.

## [1.1.4] - 2026-10-01

- Fixed the game failing to launch with Seamless Co-op.
- Fixed the Fortune of the Spiritcaller Spirit Ring not working with ER Reforged.
- Fixed the Spirit-Severing Blade not sending spirits back in ER Reforged.

## [1.1.3] - 2026-10-01

- Fixed re-using an upgraded Spirit Ash summoning more spirits instead of sending them back.

## [1.1.2] - 2026-09-30

- Fixed ghost color removal not working with ER Reforged.

## [1.1.1] - 2026-09-30

- Fixed summoning outside summoning pool areas.

## [1.1.0] - 2026-09-29

- Added summoning several different Spirit Ashes at once.
- Added re-summoning spirits without resting.
- Added summoning spirits outside summoning pool areas.

## [1.0.0] - 2026-09-29

- Initial release.
