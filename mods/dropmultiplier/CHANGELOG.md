# DropMultiplier - Changelog

## [Unreleased]

## [1.2.0] - 2026-11-05

- Fixed the reload key working outside the game window.
- Added in-game settings menu support (requires the ERNativeUI mod).
- Config file is now TOML; settings from the old INI file are kept.
- Clean code, hoping to fix false positives.

## [1.1.0] - 2026-09-28

- Added multipliers for how many crafting and upgrade materials you get.
- Separate multiplier for materials that can only be picked up once.

## [1.0.2] - 2026-09-27

- Fixed drop rates not changing with Convergence.
- Reload key now only works while the game window is focused.
- Improved logging.

## [1.0.1] - 2026-09-24

- Fixed install paths with non-ASCII characters.

## [1.0.0] - 2026-09-21

- Multiplies or fixes enemy item-drop chances.
