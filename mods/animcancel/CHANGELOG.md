# AnimCancel - Changelog

Release notes shown to users on the Nexus changelog tab: one short bullet per
user-facing change, plain text. Add new items under `[Unreleased]`; the
`deploy-nexus-mod` skill turns that section into a version when publishing.

## [Unreleased]

- Added jump option to cancel animations by jumping.
- Fixed the reload key working outside the game window.
- Changed the config file name to AnimCancelV1.toml. This fixes false detections by antivirus scanners.

## [1.1.1] - 2026-10-17

- Fixed attacks being cut right away when started while holding guard.

## [1.1.0] - 2026-10-17

- Guard, dodge and weapon swap can now each cancel a different set of animations.
- Fixed guard cancel cutting combos when dual wielding or using twin blades.
- Added in-game settings menu support (requires the ERNativeUI mod).

## [1.0.0] - 2026-10-12

- Initial release.
