fragments, how the graces, points of interest and beacons are located, the minimap's trail,
and how Map for Goblins' map API is read and its icons decoded. Adapted, with the source files

2. Map for Goblins map API
--------------------------
https://github.com/VirusAlex/ERR-MapForGoblins-DLL (sdk/mfg_map_api.h, added by soarqin)
Used for: the markers of the Map for Goblins DLL on the minimap. src/map/mfg.rs declares the
structures of the API's ABI 1 and calls MfgGetMapAPI of the loaded MapForGoblins.dll at run
time; the markers and their icons come out of that DLL while the game runs. Nothing of the mod
(code, data or art) is included in JourneyHUD, and it works without it.

3. Ideas and documentation
--------------------------
soarqin/EROverlay (https://github.com/soarqin/EROverlay): notes on how the game decides which
points of the world map show and how the beacons are stored. Followed in what is written here,
no code of it is included.

souls_vision (https://github.com/samjviana/souls_vision, GPL-3.0): consulted for where the
game keeps a target's health and posture only; JourneyHUD's target panel is written
independently and contains none of its code.

5. The game's own art
---------------------
The world map, the map icons and the health bar textures are the game's. The map and icons are
read from the player's own installation while the game runs and nothing of them is shipped.
The four health bar textures in assets/ were taken from the game's HUD and are embedded in
the DLL.
